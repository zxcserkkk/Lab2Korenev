# Домашнее задание к работе 2

## Условие задачи
Определить путь, который проедут санки с горки высотой h метров, углом наклона А
радиан и коэффициентом трения к.
**Вариант 13**

## Алгоритм и блок-схема

### Алгоритм 

1. **Начало**
2. Задать исходные данные:
   - `h`: высота горки (м).
   - `A`: угол наклона горки (рад).
   - `k`: коэффициент трения.
3. Проверить, тронутся ли санки с места:
   - Если `tan(A) <= k`, вывести сообщение «Санки не сдвинутся с места, так как tg A <= k» и перейти к п. 8.
   - Иначе продолжить.
4. Вычислить путь по склону:
   - `path_slope` = `h` / `sin(A)`
5. Вычислить путь по горизонтали до остановки:
   - `path_flat` = `h` * (1 / `k` − `cos(A)` / `sin(A)`)
6. Вычислить общий путь:
   - `total_path` = `path_slope` + `path_flat`
7. Вывести результаты расчётов с подстановкой всех значений в текст.
8. **Конец**

## Реализация программы

```c
#include <stdio.h>
#include <math.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, ".UTF-8");

    double h = 10.0;  
    double A = 0.5;   
    double k = 0.1;   

    if (tan(A) <= k)
    {
        printf("Санки не сдвинутся с места, так как tg A <= k.\n");
        getchar();
        return 0;
    }

    double path_slope = h / sin(A);
    double path_flat = h * (1.0 / k - cos(A) / sin(A));
    double total_path = path_slope + path_flat;

    printf("Санки съезжают с горки высотой %.2f м.\n", h);
    printf("Угол наклона горки: %.2f рад.\n", A);
    printf("Коэффициент трения: %.2f.\n", k);
    printf("\n");
    printf("Путь по склону: %.2f / sin(%.2f) = %.2f м.\n", h, A, path_slope);
    printf("Путь по горизонтали до остановки: %.2f * (1 / %.2f - cos(%.2f) / sin(%.2f)) = %.2f м.\n",
        h, k, A, A, path_flat);
    printf("\n");
    printf("Всего санки проедут: %.2f + %.2f = %.2f м.\n", path_slope, path_flat, total_path);

    getchar();
    return 0;
}
```
## Результат работы программы
```
Санки съезжают с горки высотой 10,00 м.
Угол наклона горки: 0,50 рад.
Коэффициент трения: 0,10.

Путь по склону: 10,00 / sin(0,50) = 20,86 м.
Путь по горизонтали до остановки: 10,00 * (1 / 0,10 - cos(0,50) / sin(0,50)) = 81,70 м.

Всего санки проедут: 20,86 + 81,70 = 102,55 м.
```
